# Publish-Ready Plan

Дата плана: `2026-06-01`.

## Перед отправкой научному руководителю

1. Обязательно пересобрать диплом с чистого состояния:
   `cd thesis && make clean && make build`.
2. Использовать актуальный текст заключения, раздатки и слайдов, синхронизированный с
   acceptance baseline `2026-06-01`, включая внешнюю stand validation по `Dokploy`.
3. В сопроводительном сообщении и устной подаче использовать уже актуальную формулировку:
   внешний `Strapi -> webhook -> Dokploy rebuild/redeploy -> Astro frontend` путь
   подтвержден на стенде проекта `2026-06-01`; при этом сам platform state `Dokploy`
   остается внешним по отношению к репозиторию.

## Что желательно довести перед финальной версией

1. Снять `underfull/overfull` warnings, из-за которых не проходит `make check`.
   Самые заметные зоны: длинные технические перечисления в главе 2 и таблицы с метриками.
2. При желании нормализовать семантику репрезентативной CMS-страницы до одного основного
   `h1`, чтобы сделать browser-level accessibility baseline еще чище.
3. Перегенерировать производные артефакты после изменения исходников:
   `handout.pdf` и, если нужны актуальные слайды для отправки, PDF/PPTX из
   `thesis/presentation/diploma-presentation.md`.

## Что можно оставить как осознанную границу ВКР

1. Отдельный route-контур `vacancies`, а не полная `/:locale/...` адресация карьерного
   модуля.
2. Route-level `SEO` для списковых страниц при `CMS`-управляемом `SEO` для
   `home-page/page/detail`.
3. Внешний platform state `Dokploy`, который не является полностью versioned частью
   репозитория.
4. Отсутствие полного `WCAG`-аудита и production-like `Lighthouse` профиля в обязательном
   контуре проверки.

## Что имеет смысл сделать уже после отправки руководителю

1. Добить `make check` до зеленого состояния и включить это в финальный release contour.
2. При необходимости приложить к материалам защиты скрин/лог именно внешнего
   `Dokploy rebuild/redeploy`, если хочется усилить доказательную часть визуально.
3. При необходимости расширить раздатку компактной таблицей
   `задача -> что реализовано -> чем подтверждено`.
