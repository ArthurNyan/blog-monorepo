\begin{description}
  \item[API] Application Programming Interface — интерфейс программирования приложений.
  \item[CI/CD] Continuous Integration / Continuous Delivery — непрерывная интеграция и доставка.
  \item[CMS] Content Management System — система управления контентом.
  \item[CRUD] Create, Read, Update, Delete — базовые операции управления данными.
  \item[DTO] Data Transfer Object — объект передачи данных между слоями приложения.
  \item[HR] Human Resources — кадровая функция и связанные с ней бизнес-процессы.
  \item[HTML] HyperText Markup Language — язык разметки гипертекста.
  \item[HTTP] HyperText Transfer Protocol — протокол передачи гипертекста.
  \item[REST] Representational State Transfer — архитектурный подход к построению веб-API.
  \item[SEO] Search Engine Optimization — поисковая оптимизация.
  \item[UI] User Interface — пользовательский интерфейс.
  \item[URL] Uniform Resource Locator — унифицированный адрес ресурса.
  \item[WCAG] Web Content Accessibility Guidelines — рекомендации по обеспечению доступности веб-контента.
  \item[WCMS] Web Content Management System — веб-система управления контентом.
\end{description}
